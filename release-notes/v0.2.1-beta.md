# Studio 64 0.2.1-beta

Play mode now runs smoothly in the browser. Before, the game kept the browser busy for the whole
of every frame, so the page refreshed only 30 (on slower computers 15) times a second and felt
slow and laggy. Now the game takes about 2 ms of each frame and the page keeps up with your screen.

## Download

- `studio64-0.2.1-beta.zip`: Studio 64 itself, one ZIP for every system

You need your own Super Mario 64 ROM (US version). Studio 64 doesn't include the game.

Unzip it and start it:

- **Windows**: double-click **Start Studio 64**. If SmartScreen says "Windows protected your PC",
  click **More info**, then **Run anyway**.
- **macOS**: right-click **Start Studio 64.command**, choose **Open**, then **Open** again.
- **Linux**: run `./start-studio64.sh` in a terminal.

The first setup downloads about 1 GB (the compiler, the engine's source) and takes 5 to 10 minutes.
Already on an earlier version? Unzip 0.2.1 next to it and start it: the setup reuses what it
downloaded before.

## What's new

- **Smooth play in the browser.** The page refreshes at your screen's rate, and every game frame
  is shown for the same time (no more slight stutter). A whole CPU core is no longer busy while
  you play, so the rest of the page stays responsive too.
- The level thumbnail taken after entering a level no longer holds up a frame.
- For developers: `node tools/perf_play.mjs` measures how smoothly play mode runs on your GPU.

Everything else is in the [changelog](https://github.com/supermochi64/studio64/blob/main/CHANGELOG.md).

If the setup fails, please open an issue with the log: click **Show details**, then **Copy the
whole log** on the setup page. Please don't attach a ROM or a playable game export.
