# Studio 64 0.1.1-beta

The second beta of Studio 64, a Super Mario 64 editor that runs the real game in your browser. It
fixes the first setup problems people hit on Windows and macOS, and it can now turn your hack into
a real N64 ROM.

## Download

- `studio64-0.1.1-beta.zip`: Studio 64 itself, one ZIP for every system

You need your own Super Mario 64 ROM (US version). Studio 64 doesn't include the game.

Unzip it and start it:

- **Windows**: double-click **Start Studio 64**. If SmartScreen says "Windows protected your PC",
  click **More info**, then **Run anyway**.
- **macOS**: right-click **Start Studio 64.command**, choose **Open**, then **Open** again.
- **Linux**: run `./start-studio64.sh` in a terminal.

Your browser opens the setup page. Drop the ROM there and press **Build Studio 64**. The first build
downloads about 1 GB and takes 5 to 10 minutes. If 0.1.0 already downloaded the compiler on this
computer, it uses that one and skips the big download.

## What's new

- **Windows setup fixed.** The first build stopped with "The Emscripten SDK was not found" right
  after the setup had installed it.
- **macOS and Linux setup fixes** from [@mikesherov](https://github.com/mikesherov): an old system
  Python (macOS often has 3.9) is passed over for the setup's own, the compiler works as the
  preprocessor and assembler on Apple Silicon, and the Zig download no longer fails on a
  certificate error.
- **ROM export.** ⋯ menu → *Export ROM hack…* makes a `.z64` for emulators and a `.bps` patch you
  can share anywhere. Your hub replaces the castle grounds and your levels take the 15 courses.
  See [ROM export](https://github.com/supermochi64/studio64/blob/main/docs/rom-export.md).
- **Plants** sit right on raised ground, and trees, bushes and rocks have no more holes.
- Custom objects with Toad's model show up, a moving platform keeps its track in another level,
  and a new shirt colour no longer shows around the M on Mario's cap.

The full list is in the [changelog](https://github.com/supermochi64/studio64/blob/main/CHANGELOG.md).

## Still rough

- Windows and macOS have only had a few real users so far. If the setup fails there, please open
  an issue with the log: click **Show details**, then **Copy the whole log** on the setup page.
- It's tested in Chrome. Other desktop browsers with WebGL should work.

Please don't attach a ROM or a playable game export to an issue.
