# Studio 64 0.1.0-beta

This is the first public build of Studio 64, a Super Mario 64 editor that runs the real game in your
browser. You build with the mouse, press `Tab`, and play what you just made. It's a beta, so expect
some rough edges.

## Download

- `studio64-0.1.0-beta.zip`: Studio 64 itself, one ZIP for every system
- `studio64-trailer-1080p.mp4`: the trailer in full size

You need your own Super Mario 64 ROM (US version). Studio 64 doesn't include the game.

Unzip it and start it:

- **Windows**: double-click **Start Studio 64**. If SmartScreen says "Windows protected your PC",
  click **More info**, then **Run anyway**.
- **macOS**: right-click **Start Studio 64.command**, choose **Open**, then **Open** again.
- **Linux**: run `./start-studio64.sh` in a terminal.

Your browser opens the setup page. Drop the ROM there and press **Build Studio 64**. The first build
downloads about 1 GB and takes 5 to 10 minutes (have about 4 GB of disk free). After that it starts
in seconds. `GETTING STARTED.txt` in the ZIP walks through it.

## What's in it

- Build mode: blocks, about 600 of the game's objects, stairs and bridges, terrain brushes (also
  in the original levels), roads, fences and plants
- New levels from 9 templates or a heightmap, your own stars and red coins
- Moving platforms, enemies built from behavior blocks, game rules like gravity and jump height
- Areas, doors, pipes, paintings, warp zones and your own hub
- Dialogs, events and cutscenes in the game's own style, and every text in the game
- A sound studio with the game's instruments, and a title screen editor with a logo maker
- Your own 3D models and textures
- Cars, Shotgun Mario, Katana Mario and a Tokyo level from my hack Shoggoth World
- Save states, slow motion, a collision view and a level check for play-testing
- Project files, a playable web game export, and level script C for the decomp

All of it works without AI. There's an optional assistant you can connect (Claude, OpenAI, Gemini,
OpenRouter or a local model); if you don't, you won't see it anywhere.

## What's rough

- **Windows and macOS haven't been tested on real machines.** The launchers are reviewed and the
  PowerShell launcher ran under PowerShell 7, but the full setup has only run start to finish on
  Linux (Ubuntu 22.04 and 24.04, Debian 12, Fedora, Arch). If you're on Windows or a Mac, you're the
  first. Please tell me how it went.
- It's tested in Chrome. Other desktop browsers with WebGL should work, but they haven't been
  tested.
- The first setup is slow on a busy or older machine (it compiles the whole game).
- It exports a web game, not a ROM. For a ROM you'd take the level script C export into the decomp
  and build it yourself.

## Found a bug?

Open an issue on GitHub. Say what you did and what happened instead, and which system and browser
you use. The version is at the bottom of the Help menu. If the setup failed, click
**Show details** and then **Copy the whole log** on the setup page and paste it in. If the game
crashed, the red lines from the browser console (`F12`) help a lot.

Please don't attach a ROM or a playable game export.
