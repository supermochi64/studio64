# Studio 64 0.2.0-beta

Studio 64 no longer ships any of the game's code or data. The setup downloads the engine's source
from [sm64ex](https://github.com/sm64pc/sm64ex) the first time and adds Studio 64's own parts to it;
the game is then built from **your own** ROM, as before. Nothing changes in how you use it, and
the ZIP is smaller (19 MB).

## Download

- `studio64-0.2.0-beta.zip`: Studio 64 itself, one ZIP for every system

You need your own Super Mario 64 ROM (US version). Studio 64 doesn't include the game.

Unzip it and start it:

- **Windows**: double-click **Start Studio 64**. If SmartScreen says "Windows protected your PC",
  click **More info**, then **Run anyway**.
- **macOS**: right-click **Start Studio 64.command**, choose **Open**, then **Open** again.
- **Linux**: run `./start-studio64.sh` in a terminal.

The first setup downloads about 1 GB (the compiler, the engine's source) and takes 5 to 10 minutes.
Already on an earlier version? Unzip 0.2.0 next to it and start it: the setup reuses what it
downloaded before.

## What's new

- **No game code or data in Studio 64's download or repository.** The engine's source comes from
  sm64ex during the setup, checked file by file. The game you get is the same as before, byte for
  byte.
- The setup works on Windows, macOS and Linux in the automatic test on GitHub.

Everything else is in the [changelog](https://github.com/supermochi64/studio64/blob/main/CHANGELOG.md).

If the setup fails, please open an issue with the log: click **Show details**, then **Copy the
whole log** on the setup page. Please don't attach a ROM or a playable game export.
