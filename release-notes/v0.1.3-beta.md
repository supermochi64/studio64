# Studio 64 0.1.3-beta

Setup fixes for **macOS** and **Windows**.

## Download

- `studio64-0.1.3-beta.zip`: Studio 64 itself, one ZIP for every system

You need your own Super Mario 64 ROM (US version). Studio 64 doesn't include the game.

Unzip it and start it:

- **Windows**: double-click **Start Studio 64**. If SmartScreen says "Windows protected your PC",
  click **More info**, then **Run anyway**.
- **macOS**: right-click **Start Studio 64.command**, choose **Open**, then **Open** again.
- **Linux**: run `./start-studio64.sh` in a terminal.

Already on an earlier version? Unzip 0.1.3 next to it and start it: the setup reuses what it
downloaded before.

## What's new since 0.1.2

- **macOS:** the setup's build no longer stops with "file not found" for a level's textures. Apple's
  bundled `make` didn't understand one line of the build rules. Thanks
  [@mikesherov](https://github.com/mikesherov)!
- **Windows:** the launcher checks the Node.js download without `Get-FileHash`, which some Windows
  PowerShell setups can't load, and tells you when it starts Studio 64.

Everything else is in the [changelog](https://github.com/supermochi64/studio64/blob/main/CHANGELOG.md).

If the setup fails, please open an issue with the log: click **Show details**, then **Copy the
whole log** on the setup page. Please don't attach a ROM or a playable game export.
