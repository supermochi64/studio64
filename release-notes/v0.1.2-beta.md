# Studio 64 0.1.2-beta

A fix for **ROM export**: on most computers it didn't find the base ROM that comes with Studio 64
and tried to build it itself (a long build that fails on Windows and macOS). Now the base ROM fits
every computer, so an export takes seconds everywhere.

## Download

- `studio64-0.1.2-beta.zip`: Studio 64 itself, one ZIP for every system

You need your own Super Mario 64 ROM (US version). Studio 64 doesn't include the game.

Unzip it and start it:

- **Windows**: double-click **Start Studio 64**. If SmartScreen says "Windows protected your PC",
  click **More info**, then **Run anyway**.
- **macOS**: right-click **Start Studio 64.command**, choose **Open**, then **Open** again.
- **Linux**: run `./start-studio64.sh` in a terminal.

Already on 0.1.1? Unzip 0.1.2 next to it and start it: the setup reuses what it downloaded before.

## What's new since 0.1.1

- **ROM export works on every computer** with the base ROM that ships with Studio 64. Before, it
  only matched the computer it was made on.
- The automatic setup test on GitHub runs again.

Everything new in 0.1.1 (the Windows setup fix, macOS and Linux setup fixes, ROM export, plants) is
in the [changelog](https://github.com/supermochi64/studio64/blob/main/CHANGELOG.md).

Please don't attach a ROM or a playable game export to an issue.
