# Sandbox

An open-city game for the Nintendo 64: a sunny coastal city, a crew in Palm Court, cars and bikes,
shops, gang turf, missions, and a hero who moves like a 3D platformer star (triple jumps, long
jumps, backflips, wall kicks, ground pounds, ledge grabs, pole climbing).

It's a standalone N64 ROM. Nothing in it comes from Nintendo: no code, models, textures, music or
sound. Every model, texture, song and voice line is generated by the scripts in `tools/`, and the
engine is written here on top of [libdragon](https://github.com/DragonMinded/libdragon) and
[Tiny3D](https://github.com/HailToDodongo/tiny3d). So the ROM itself can be shared, and it plays in
N64 emulators (ares, Project64, mupen64plus/RetroArch with the paraLLEl core) and on a real console
with a flash cart. It needs the Expansion Pak (8 MB), which every common emulator turns on by default.

## Playing

| On foot | |
|---|---|
| Stick | run (tilt a little to walk) |
| A | jump; again on landing for the double and triple jump |
| Z + A | while running: long jump; standing: backflip |
| Z | crouch; in the air: ground pound |
| B | punch, kick combo; running: dive; with a gun: fire |
| R | aim, lock on to the nearest person |
| C-up | get in or out of a car, a bike |
| D-pad left/right | change weapon |
| D-pad up / down | recruit the person you face into your crew / send the crew home |
| L | camera behind you |
| Start | pause: the map, the controls |

| Driving | |
|---|---|
| A / B | gas / brake and reverse |
| Z | handbrake (on the BMX: hop) |
| L | horn |
| R + B | shoot from the car |
| D-pad up | the siren (police cars) |

Jump against a wall and press A again for a wall kick. Run into a lamp post, a palm or a pole to
climb it. Grab ledges, drop down, climb back up.

## Building

Needs Linux (or WSL), Node.js 18 or newer, `git`, `curl`.

```sh
games/sandbox/tools/setup.sh      # once: the N64 toolchain, libdragon and Tiny3D in ~/n64
export N64_INST=~/n64/inst
cd games/sandbox && make          # writes sandbox.z64
```

`make` runs `node tools/build_assets.mjs` first. That script makes the city, the models, the
textures, the fonts, and (when `tools/audio.mjs` or `tools/lib/synth.mjs` changed) the music and the
voices. Then libdragon's tools convert everything for the console.

### Testing in an emulator

`tools/emu.mjs` runs a ROM in ares on a virtual display, reads the game's debug output and takes
screenshots. Test builds play themselves:

```sh
make TEST=all     # 20 checks: moves, cars, bikes, shooting, recruiting, a shootout, sound, frame times
node tools/emu.mjs sandbox_test_all.z64 --seconds 300 --until "TEST done" --out shots/all
make TEST=tour    # screenshots round the city by day and night
make TEST=model   # the hero's poses and the townspeople up close
```

## Changing it

Everything is made by code, so changing the game means changing a script and running `make`.

| To change | Look at |
|---|---|
| The city's layout, districts, gangs, buildings, props | `tools/city.mjs` (`DMAP`, `DISTRICT_NAMES`, `GANG_OF`, the `house`, `shop`, `tower`, `park` ... functions) |
| Textures | `tools/textures.mjs`: each is painted with `tools/lib/paint.mjs` (shapes, gradients, seamless noise), 32x32 for the city |
| People, cars, bikes, weapons, pickups | `tools/models.mjs` (meshes) and the tables in `src/vehicle.c` (`g_vdefs`), `src/weapon.c` (`g_weapons`), `src/actor.c` (looks) |
| Music | `tools/audio.mjs`: songs are written as chords, melodies and drum patterns; `SONGS` lists them in the order of `MUS_` in `src/sound.h` |
| Voices | `tools/audio.mjs` `VOICES`: phonemes, lengths and a pitch line per line; the order matches `VO_` in `src/sound.h` |
| The hero's moves | `src/actor.c` (states, physics, poses), `src/player.c` (controls) |
| Missions, the shop | `src/mission.c`, `src/shop.c` |

The city streams in 64 m chunks. Each chunk has a detailed model in four quadrants (culled one by
one), a layer of small things drawn only up close, lit windows drawn only at night, and a simple far
model. A prop added with `emit()` goes in the detailed model, `fine()` in the small things, `night()`
in the night layer, and `lod()` in the far model.
