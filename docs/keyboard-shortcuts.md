# Keyboard shortcuts

Every key on one page. In the studio, `?` shows the same list, and tooltips show the key of each
button. On a Mac, `Ctrl` is `⌘`.

Shortcuts never fire while you type in a text field.

## Everywhere

| Key | |
|---|---|
| `Ctrl+P` | Command palette: every action, tool and level by name |
| `Ctrl+K` | Level launcher (`L` too, when you are not playing) |
| `Tab` | Switch between Play and Build |
| `Ctrl+J` | Show or hide the side column (chat, edits, stars) |
| `?` | Shortcut sheet |
| `Esc` | Close a panel, back to the game |
| `Y` | Story |
| `M` | Sound studio |
| `P` | Game rules (in build mode: play from the spot under the mouse) |
| `F3` | Play-test tools |
| `F2` | Debug view (collision, hitboxes, Mario info) |
| `/` | Write to the AI assistant (only when AI is on) |

## Playing

The game's buttons on the keyboard. A gamepad works too.

| Key | N64 button | |
|---|---|---|
| `W` `A` `S` `D` | Control stick | Run |
| `Space` or `K` | A | Jump |
| `J` | B | Punch, kick, talk |
| `Shift` or `L` | Z | Crouch, ground pound |
| `Enter` | Start | Pause |
| Arrow keys | C buttons | Camera |
| `Q` | L | |
| `R` | R | Camera mode |
| `Esc` | | Give the mouse back to the studio |

## Build mode: camera

| Key | |
|---|---|
| Right-drag or middle-drag | Orbit around what is under the mouse |
| `Shift` + drag | Pan |
| Wheel, `Ctrl` + drag | Zoom toward the mouse |
| `Alt` + left / middle / right drag | Orbit / pan / zoom (Maya style) |
| Double-click | Center on that spot |
| `F` (or Numpad `.`) | Frame the selection |
| `Home` | Frame Mario |
| `Shift+Home` | Whole level from above |
| Numpad `1` `3` `7` | Front / right / top view (`Ctrl`: the opposite side) |
| Numpad `2` `4` `6` `8` | Orbit in 15° steps |
| Numpad `+` `-` (or `=` `-`) | Zoom in / out |
| Hold right mouse + `W` `A` `S` `D`, `Q` `E` | Fly; `Q` `E` down and up, `Shift` faster |

## Build mode: editing

| Key | |
|---|---|
| Click | Select |
| Drag | Slide over the ground (`Shift`: up and down) |
| `Shift`/`Ctrl` + click | Add to the selection |
| Drag on empty space | Selection box |
| `Ctrl+A` | Select everything you built |
| `1` `2` `3` | Move / rotate / resize handles |
| `R` | Rotate 45° (also while placing) |
| `G` | Drop to the ground |
| `Ctrl+D` | Duplicate |
| `Del` | Delete |
| `Ctrl+C` / `Ctrl+V` | Copy / paste (also between levels) |
| `Ctrl+Z` | Undo the newest edit here (this level, or a project-wide one like a story or asset edit) |
| `Ctrl+Shift+Z` or `Ctrl+Y` | Redo |
| `Alt` while dragging | Ignore the grid |
| `O` | Scene panel: everything in this level |
| `F2` (in the scene panel) | Rename |
| `P` | Play from the spot under the mouse |
| Right-click or `Esc` | Stop placing |
| `Tab` | Back to playing |

## Terrain brushes

| Key | |
|---|---|
| Hold left mouse | Sculpt or paint |
| `Shift` | Invert (raise ↔ lower) |
| `Ctrl` | Smooth |
| `[` `]` or `Alt` + wheel | Brush size |

## Roads and nature

| Key | |
|---|---|
| Click · double-click / `Enter` | Add a road or fence point · finish |
| `Backspace` | Take the last point back while drawing |
| `Del` | Remove the selected point (no point selected: the road or fence) |
| `Esc` | Stop drawing · done editing |
| Hold left mouse (Nature tab) | Plant |
| `Shift` + drag (Nature tab) | Erase plants |
| `[` `]` or `Alt`+wheel | Brush size |
| `Shift`+click a plant kind | Plant only that kind |

## Path tool

When you draw a path for a moving platform or a patrol ([Objects](objects.md#the-path-tool)):

| Key | |
|---|---|
| Click | Add a point at the end (on a segment: insert) |
| `Ctrl` + click | Add a point on the ground |
| Drag a point | Move it (`Shift`: up and down) |
| Right-click a point, or `Del` | Delete it |
| `Enter` or `Esc` | Done |
